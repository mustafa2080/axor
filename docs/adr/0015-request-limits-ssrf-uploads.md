# ADR-0015: حدود الطلبات والحماية من SSRF ورفع الملفات

- **الحالة:** منفّذ (2026-11-01) — الباك. حدود الحجم والنوع والوقت اتظبطت في `app.ts`، وحارسين ساكنين جداد.
- **السياق:** بنود TASKS.md: «تحديد حجم الطلبات وأنواع الملفات المقبولة» و«حماية من SSRF لو في وظائف بتستقبل URLs». الحد الأقصى للـ body كان 1 ميجا (أكبر بكتير من أي طلب حقيقي)، وFastify بيقبل `text/plain` افتراضياً، ومفيش حدود وقت صريحة. وفي نفس الوقت المشروع مفيهوش رفع ملفات ولا أي اتصال خارجي من الخادم.

## القرار

1. **حجم الـ body:** `MAX_BODY_BYTES = 65_536` (64 كيلوبايت). كل الطلبات JSON صغير، فده أضعاف أكبر طلب حقيقي. الزيادة بترجع 413 (قبل القراءة لو الـ `Content-Length` المعلن أكبر).
2. **النوع:** JSON بس. `text/plain` اتشال من الـ parsers، فأي نوع تاني (نموذج `x-www-form-urlencoded` أو `multipart/form-data` أو XML أو `octet-stream`) بيرجع 415.
3. **طول الـ path params:** `maxParamLength = 100` (الأكواد والـ UUID أقصر بكتير). الأطول بيرجع 414.
4. **الوقت:** `requestTimeout = 30s` و`headersTimeout = 15s`، عشان العميل البطيء (slowloris) ما يفضلش ماسك اتصال.
5. **رفع الملفات:** مش مدعوم. مفيش parser للـ multipart، وحارس ساكن بيفشل لو ظهر `@fastify/multipart` أو `multer` أو `busboy` أو `formidable` في الـ dependencies أو الـ imports. أول ميزة رفع لازم تيجي بتصميمها (حجم، أنواع بالمحتوى مش بالامتداد، تخزين برّه الـ web root، فحص).
6. **SSRF:** مفيش مكان في الخادم بيعمل طلب لعنوان المستخدم بيأثر فيه. الحارس الساكن (`outbound-safety.test.ts`) بيفشل لو ظهر HTTP client (`axios` أو `undici` أو `fetch(` ...) أو socket خام أو DNS أو `child_process` أو `new URL(...)` من غير `env.`. الاستثناء الوحيد دوال تحليل الـ IP في `node:net` (`isIPv4`/`isIPv6`) اللي بيستخدمها `maskIp`، ومش بتفتح اتصال.

## خارج النطاق

- حدود الـ nginx/Apache (`client_max_body_size` ونفس الحدود على الـ headers): بند نشر، ومحتاج يتظبط على نفس القيمة أو أقل.
- حجم الـ headers: الافتراضي بتاع Node (16 كيلوبايت).
- الحدود على عدد الاتصالات المتزامنة والـ rate limit العام: بند تاني (الـ rate limit موجود على `/auth/*` بس).
- حماية SSRF الفعلية (allowlist ومنع النطاقات الخاصة ومنع الـ redirects): هتتصمم مع أول ميزة بتحتاجها (webhooks أو مزوّد بريد بعنوان قابل للتعديل).

## النتائج

- أي طلب أكبر من 64 كيلوبايت هيتوقف، فلو ميزة جاية محتاجة أكبر (استيراد بيانات مثلاً) لازم تعدّل الحد لمسار بعينه مش للتطبيق كله، وتحدّث الـ ADR ده.
- الحارس regex على نص الملف: مش بيمسك استدعاء متبني ديناميكياً (`globalThis['fe'+'tch']`)، والمراجعة هي الدفاع التاني.
- الـ 415 والـ 414 والـ 413 بترجع بنفس شكل الأخطاء الموحّد (`BAD_REQUEST`).
