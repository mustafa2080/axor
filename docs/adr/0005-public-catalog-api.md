# ADR-0005: واجهة الكتالوج العامة (قراءة فقط)

- **الحالة:** مقترح للتنفيذ (2026-10-19) — يعتمد على ADR-0003 (الجداول) ويسبق لوحة إدارة الكتالوج.
- **السياق:** الصفحة الرئيسية وصفحة اختيار الباقة محتاجين يعرضوا الأنظمة والأنشطة والباقات للزائر قبل التسجيل.

## القرار

1. **Endpoints عامة بدون مصادقة، قراءة فقط:**
   - `GET /api/v1/catalog/products`: كل الأنظمة اللي مش `disabled` (الـ `coming_soon` بتظهر عشان الموقع يعرضها)، مع أنشطتها `active` فقط.
   - `GET /api/v1/catalog/products/:productCode/plans[?activity=<code>]`: الباقات `active` لنظام `available` فقط.
2. **النسخة الحالية بس:** كل باقة بتظهر بنسخة `plans.current_version_id` (ADR-0003 #4)، مش آخر نسخة ولا النسخ القديمة. لو `current_version_id` فاضي أو بيشاور على نسخة تخص باقة تانية، الباقة ما بتظهرش (الـ join بيشترط `plan_versions.plan_id = plans.id`).
3. **فلتر النشاط:** `?activity=` بيرجّع باقات النشاط ده + الباقات اللي مالهاش نشاط (بتخص كل الأنشطة). نشاط مجهول أو معطّل أو تابع لنظام تاني = 404. باقات مربوطة بنشاط معطّل ما بتظهرش.
4. **404 موحّد:** نظام غير متاح (`coming_soon` أو `disabled` أو مش موجود) ونشاط غلط بيرجعوا نفس الـ 404 من غير ما نقول أنهي واحد الغلط.
5. **الحقول العامة بس:** `code` و`name` و`status` للأنظمة، و`code` و`activity` و`version` و`price` (`amountMinor` بأصغر وحدة + `currency` + `billingPeriod`) و`trialDays` و`limits` (null = غير محدود) و`features` للباقات. مفيش أي `id` ولا تواريخ ولا أعمدة داخلية (مختبر).
6. **مفيش أي قيمة بتيجي من العميل:** السعر والمدة والحدود بتتقرا من قاعدة البيانات بس. المدخلات الوحيدة: `productCode` و`activity` بصيغة `[a-z0-9_-]` (حد أقصى 50)، وأي query parameter تاني = 400. أي method غير GET = 404.
7. **مش مربوط بـ `TenantScope`:** بيانات مرجعية مشتركة لكل الزوار. الـ Repository (`catalog.repository.ts`) للقراءة فقط؛ الكتابة هتبقى في وحدة إدارة المنصة وبصلاحيات المنصة.
8. **الحماية:** حد 120 طلب/دقيقة لكل IP، و`Cache-Control: public, max-age=60` على الردود الناجحة (نفس الرد للكل). تغيير سعر بياخد لحد دقيقة ليظهر.

## خارج النطاق

إدارة الكتالوج (إنشاء الأنظمة والأنشطة والباقات ونسخ جديدة)، بدء التجربة والاشتراك، جدول Feature/Entitlement منفصل (الحدود والميزات حالياً JSON جوه `plan_versions`)، ومحتوى فعلي للباقات والأسعار (قرار المدير).

## النتائج

- الواجهة تقدر تبني الصفحة الرئيسية وصفحة الباقات على الـ API ده بدون أي تغيير في الجداول.
- قاعدة التطوير فاضية: الـ endpoints بترجّع `[]` / 404 لحد ما يتضاف محتوى (أنظمة وباقات) بقرار المدير.
